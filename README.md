# AI Radar

> Frontier model pricing & AI company news — 20 models, 12 companies, cross-validated.

AI Radar pulls live pricing for 20 frontier AI models from OpenRouter, plus top 3 stories per tracked company from Hacker News (community) cross-validated against official company RSS feeds (official). Updated every 6 hours. Deployed as a static GitHub Pages site.

AI Radar 从 OpenRouter 拉取 20 个前沿 AI 模型的实时价格，并从 Hacker News（社区）+ 各公司官方 RSS（官方）交叉验证每家被追踪公司的 Top 3 新闻。每 6 小时更新。部署为 GitHub Pages 静态站点。

---

## What's tracked

- **Pricing** — 20 models, selected from 380+ on OpenRouter, grouped by output price tier:
  - Tier S — Super-flagship (>$30/M output)
  - Tier A — Flagship ($10-30/M output)
  - Tier B — Mainstream ($1-10/M output)
  - Tier C — Economy (<$1/M output)
- **News** — 12 AI companies × 3 stories max, last 7 days, cross-validated
- **Changelog** — last 30 days of price changes (added/removed/changed)

## Tracked companies

OpenAI · Anthropic · Google (Gemini/DeepMind) · xAI · DeepSeek · Mistral · Meta (Llama) · Alibaba (Qwen) · Zhipu (GLM) · Moonshot (Kimi) · MiniMax · Stepfun

## Data sources (all free, no API key required)

| Source | What | Auth |
|---|---|---|
| [OpenRouter `/api/v1/models`](https://openrouter.ai) | Model pricing (pass-through) | None |
| [HN Algolia API](https://hn.algolia.com/api) | Community news | None |
| [HN Firebase API](https://hacker-news.firebaseio.com/v0/) | Cross-checking | None |
| Company blog RSS | Official news | None |

## How it works

```
GCP systemd timer (every 6h)
  ↓
scripts/fetch_pricing.py  → data/pricing.json
scripts/fetch_news.py     → data/news.json
scripts/detect_changes.py → data/changelog.json
scripts/build.py          → index.html
  ↓
git push → w1977-0/model-price-radar
  ↓
GitHub Pages auto-rebuild → https://w1977-0.github.io/model-price-radar/
```

## Local run

```bash
python3 scripts/fetch_pricing.py
python3 scripts/fetch_news.py
python3 scripts/detect_changes.py
python3 scripts/build.py
# open index.html in browser
```
